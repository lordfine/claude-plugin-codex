# 默认自主执行，敏感操作经 Codex 判断

Claude Code 在委派范围内默认自主执行；大量删除或覆盖、凭据读取或外传、远端写入、生产部署或改库、Git 推送或强制改历史等操作须先由 Codex 判断。生产部署只有在用户明确纳入当前任务时才可由 Codex 自主批准；凭据外传不得自动批准，凭据读取和远端 Git 历史改写交由用户决定。

原生窗口方案优先验证 `ask: ["*"]` 与本地 `PermissionRequest` 回调：普通调用由本地规则快速决定，敏感或不确定调用才交给 Codex 判断，避免每次工具调用都消耗 Codex token。Codex 门禁失联时不自动放行，用户可在 Claude 原生窗口手动批准或拒绝；恢复后 Codex 补读谁批准了哪项操作。子代理继承同一门禁。该组合在当前 Windows、CCswitch 和自定义模型环境中仍需实测；验证失败时不能将可能失效后放行的普通 CLI Hook 当作严格门禁。
