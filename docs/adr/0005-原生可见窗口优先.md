# 新任务优先打开原生 Claude Code 窗口

新委派任务应自动打开可见的原生 Claude Code 交互窗口，供用户实时观察进度。用户在窗口中输入或中断时进入人工接管，Codex 暂停自动下达指令，直到用户明确交还控制权。委派任务默认运行上限为 90 分钟和 120 轮，逐任务可调整；到限后保存状态并通知用户。

该选择以现有 Claude Code 使用体验为优先。先做最小验证：终端桥持有 Claude Code 原生交互会话，在可见终端显示，并实测运行中追加指令、中断与分层回执。只有关键动作实测可靠，才把它定为正式路径；若失败，向用户说明实证结果后再讨论其他可见窗口方式。

接入正在执行的既有会话时，默认等当前轮结束，再按精确会话 ID 接入；只有原位接入不可用时才重启续接。用户明确要求立即接管时才中断当前轮。关闭可见窗口只隐藏显示，后台任务继续运行；取消任务需要单独操作。
