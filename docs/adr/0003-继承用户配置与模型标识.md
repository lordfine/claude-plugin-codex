# 默认继承 Claude Code 当前配置

新委派任务默认使用启动当下 Claude Code 的有效用户配置，不由插件强制指定模型或回退模型；用户显式指定模型时，原样传递模型标识，包括 `glm-5.3` 等非 Anthropic 名称。Codex 只可从 CCswitch 当前配置提供的模型中选择；指定标识不在当前可用配置中时，拒绝启动并列出可选模型。Codex 不自行切换 CCswitch 供应商或修改其配置文件；用户切换配置或明确要求修改配置时例外。接入既有窗口时保留该窗口当前配置，若需换模型则先暂停并按原会话 ID 重启。

运行中的任务以启动时的配置为目标，新任务读取最新配置。Claude Code 会热重载部分设置，CCswitch 本地路由也可能立即切换上游，因此不能仅凭进程启动时的快照声称配置已固定。实现须检测配置变化及实际路由；无法保证固定时暂停任务并通知用户，由用户决定是否按新配置续接。这样既沿用用户现有配置，也避免插件内置模型名单覆盖用户选择。
